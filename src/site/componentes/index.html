Componentes

Cada página abaixo é, ao mesmo tempo, fixture de teste e catálogo demonstrativo (RF-07/RF-11). O catálogo cobre todos os componentes de getbootstrap.com/docs/5.3/components, além de formulários. Nenhuma página exige classes .br-* (RF-03). Esta tabela resume a matriz completa de docs/requisitos.md §6.

Comparar com o Bootstrap puro: desligue a chave Aplicar GOV.BR DS no topo de qualquer página. A escolha vale para todas as páginas do catálogo e fica no endereço (?tema=bootstrap ou ?tema=dsgovbr), para compartilhar o link no mesmo modo.

Legenda de status: Planejado (ainda não implementado) · Experimental (implementado, sem cobertura de regressão completa) · Estável · Limitado (só as variantes e estados documentados) · Não suportado (sem adaptação própria; recebe só os tokens globais).
