Web components (<dsgovbr-header>, -menu, -footer, -breadcrumb)

JS opcional que encapsula as composições do exemplo de painel (Header, Menu, Footer e Breadcrumb do GOV.BR DS) em custom elements. Eles geram as mesmas classes Bootstrap documentadas nas outras páginas, em light DOM (sem Shadow DOM): o CSS do tema e o seu continuam valendo. O JS do Bootstrap (bootstrap.bundle) segue sendo quem abre o menu, os dropdowns e a busca.

Uso

Carregue o arquivo com defer (ou no fim do <body>), para os filhos já existirem quando o componente monta. O skip link e o <main id="conteudo"> ficam no HTML da página, antes do header. 

<link rel="stylesheet" href="dist/dsgovbr-bootstrapped.min.css">
<script src="dist/dsgovbr-bootstrapped-modo.js"></script>          <!-- opcional: botão de modo escuro -->
<script src="dist/dsgovbr-bootstrapped-componentes.js" defer></script>
<script src="bootstrap.bundle.min.js" defer></script>

Cada componente lê os filhos e os atributos uma vez, ao conectar, e troca o conteúdo pelo HTML final: o que você escreve é só a declaração. Mudar um atributo depois remonta o componente. Os valores viram texto e atributos, nunca HTML.

Elementos filhos

As partes internas também são elementos. Eles só carregam atributos e conteúdo para o componente pai, que os troca pelo HTML final; sozinhos, fora de um pai, não aparecem. Onde se espera um <dsgovbr-item>, um <a href> comum também vale.

Breadcrumb (<dsgovbr-breadcrumb>)

Início Cadastros Usuários 
<dsgovbr-breadcrumb rotulo="Trilha de navegação">
  <dsgovbr-item href="/">Início</dsgovbr-item>
  <dsgovbr-item href="/cadastros">Cadastros</dsgovbr-item>
  <dsgovbr-item>Usuários</dsgovbr-item>   <!-- o último é a página atual (aria-current="page") -->
</dsgovbr-breadcrumb>

Atributos: rotulo (aria-label do <nav>; padrão "Trilha de navegação") e compacto (margem inferior reduzida, aplicada automaticamente dentro do header).

Header (<dsgovbr-header>)

Abaixo, com estatico para não grudar no topo desta página. No exemplo de painel ele fica fixo (.sticky-top), junto com o breadcrumb, o título e as ações da página; ao rolar, a linha de cima (logo, assinatura e ações) e o subtítulo somem e fica só o título e a busca (atributo data-dsgovbr-rolado no host).

Menu (<dsgovbr-menu>)

O próprio elemento é o .offcanvas.offcanvas-start: o id dele é o alvo do botão do header.

Início Usuários Grupos e permissões Configurações Portal do órgão Conteúdo publicado sob a licença Creative Commons Atribuição 4.0. 
<dsgovbr-menu id="menu-principal" titulo="Sistema" logo="logo.svg">
  <dsgovbr-item href="/" icone="fas fa-home">Início</dsgovbr-item>
  <dsgovbr-pasta rotulo="Cadastros" icone="fas fa-users" aberta id="menu-cadastros">   <!-- Collapse -->
    <dsgovbr-item href="/usuarios" icone="fas fa-user" atual>Usuários</dsgovbr-item>
  </dsgovbr-pasta>
  <dsgovbr-menu-rodape rotulo-redes="Redes sociais">
    <dsgovbr-logo src="orgao.svg" alt="Logo do órgão"></dsgovbr-logo>
    <dsgovbr-item href="https://…" externo>Portal do órgão</dsgovbr-item>
    <dsgovbr-rede href="https://…" icone="fab fa-youtube">YouTube</dsgovbr-rede>
    <dsgovbr-aviso>Licença <strong>CC BY 4.0</strong>.</dsgovbr-aviso>
  </dsgovbr-menu-rodape>
</dsgovbr-menu>

Atributos: titulo, logo, rotulo (aria-label do <nav>; padrão "Menu principal") e rotulo-fechar (padrão "Fechar o menu"). atual marca o item da página (.active e aria-current="page"); aberta na pasta a deixa aberta; o id dela, se houver, vira o do Collapse. O <dsgovbr-menu-rodape> mostra, nesta ordem, logos, itens externos, redes e aviso.

Footer (<dsgovbr-footer>)

Sobre Termos de uso Fale conosco Facebook YouTube Projeto não oficial, sem endosso do governo. Licença MIT. 
<dsgovbr-footer logo="logo-negativo.svg" logo-alt="Logo do sistema"
                assinatura="assinatura.svg" assinatura-alt="Assinatura do órgão">
  <dsgovbr-coluna titulo="Sistema">
    <dsgovbr-item href="/sobre">Sobre</dsgovbr-item>
  </dsgovbr-coluna>
  <dsgovbr-rede href="…" icone="fab fa-facebook-f">Facebook</dsgovbr-rede>
  <dsgovbr-aviso>Texto legal (aceita HTML)</dsgovbr-aviso>
</dsgovbr-footer>

Sempre no modo escuro (data-bs-theme="dark" no <footer>), com fundo --background-dark. Atributos: logo, logo-alt, assinatura, assinatura-alt e rotulo-redes (padrão "Redes sociais"). Cada <dsgovbr-coluna> vira um <nav> com o titulo como <h2> e aria-label; o nome acessível de cada rede é o texto dela.

Acessibilidade

  • O host de <dsgovbr-header>, -footer e -breadcrumb usa display: contents: os landmarks <header>, <footer> e <nav> reais é que existem na árvore.
  • Botões só com ícone têm aria-label; o ícone é aria-hidden. Menu, dropdowns e busca usam os atributos data-bs-* do Bootstrap (foco, Escape e aria-expanded vêm do plugin).
  • Antes de montar, o CSS esconde o componente (visibility: hidden até o atributo data-dsgovbr-montado), para a declaração crua não "piscar". Sem o JS, ele fica oculto.

Diferenças conhecidas em relação ao GOV.BR DS

  • Não usam as classes .br-* nem o JS do GOV.BR DS: o resultado é o das composições Bootstrap documentadas em Navbar, Offcanvas, List group e Breadcrumb.
  • O recolhimento de níveis do breadcrumb e a anatomia completa do .br-header (menu de links, mais de uma linha de ações) não são reproduzidos; o que não está nos atributos e elementos acima pode ser feito com HTML livre em <dsgovbr-acoes> e <dsgovbr-aviso>.
  • O conteúdo é lido uma vez: adicionar filhos depois de montado não atualiza o componente (altere um atributo ou recrie o elemento).
  • Experimental: a API (atributos e elementos) pode mudar antes da 1.0.
