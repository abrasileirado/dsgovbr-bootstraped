Badge estático (.badge)

Adaptação visual do badge Bootstrap para a tag padrão do GOV.BR DS. Mantém somente classes públicas Bootstrap e não requer JavaScript nem classes .br-*.

Padrão e variantes

Padrão Primário Secundário Sucesso Erro Atenção Informação Claro Escuro

Contador em um botão

O badge continua informativo; a ação e o foco pertencem ao botão Bootstrap.

Uso acessível

O texto sempre identifica o significado da variante; a cor não é o único indicador. Para fundos coloridos, use .text-bg-*, que escolhe texto contrastante. Não use esta adaptação para tags removíveis, selecionáveis ou com interação própria.

Diferenças e limites em relação ao GOV.BR DS

  • Este suporte cobre somente o badge estático: fundo padrão, variantes de cor e contador.
  • As variantes .text-bg-* usam as cores e o cálculo de contraste do Bootstrap; não reproduzem todos os estados de cor da tag GOV.BR DS.
  • Tags selecionáveis, removíveis, de status circular, contagem com comportamento especial e interação não são suportadas.
  • O badge não recebe foco nem papel interativo próprio; controles interativos continuam sendo elementos Bootstrap separados.
